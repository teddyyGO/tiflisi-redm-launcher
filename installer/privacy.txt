თქვენი სახელი, ანგარიშები, ფაილები და კომპიუტერის მონაცემები არასოდეს იგზავნება.

----------------------------------------

The launcher sends only what it needs to work:
- Server list and status: from Cfx.re and from the servers you look at.
- Updates: checks GitHub for new versions.
- When you press Join: that server gets the launcher version and a random install number.
- Anonymous stats: while the launcher is open, once a minute the Tiflisi 1898 server gets the launcher version, its language, whether the game is running and the same random number. Turn it off any time: Settings > "Share anonymous launcher stats".

Your name, accounts, files and PC details are never sent.
